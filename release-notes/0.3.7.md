## Stackroot 0.3.7

Download and run `Stackroot-Setup-0.3.7.exe` on **Windows 10/11 (64-bit)**. Update over **0.3.6** — sites, databases, and settings are kept.

### Secure downloads

- **Composer and HTTPS work out of the box** — fresh PHP installs can reach the internet securely (package installs, browser tooling downloads, and similar HTTPS calls) without manual certificate setup.

### PHP versions

- **Restart one version without stopping the others** — when several PHP versions are running for your sites, restarting or recovering one no longer takes the rest down with it.
- **PHP 8.5.9 available** — the latest 8.5 patch is in the catalog. Earlier 8.5 builds you may already use stay listed and manageable.

### Nginx

- **Nginx 1.31.4 available** — you can install the newer mainline build from the catalog. The current stable default remains available for existing setups.

### Upgrading from 0.3.6

Your sites, databases, and settings are preserved. No manual steps required. After updating, open Stackroot once so PHP settings refresh (including secure HTTPS support).
