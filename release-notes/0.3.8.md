## Stackroot 0.3.8

Download and run `Stackroot-Setup-0.3.8.exe` on **Windows 10/11 (64-bit)**. Update over **0.3.7** — sites, databases, and settings are kept.

### Background processes

- **Nothing stays hidden** — a process that can no longer start (for example its PHP version was replaced) stays in your list with a clear **Needs update** label and a short reason, so you can edit it, turn off auto-start, or remove it.
- **Auto-start keeps going** — if one process cannot start when Stackroot opens, the others you set to start automatically still start.

### Upgrading from 0.3.7

Your sites, databases, and settings are preserved. No manual steps required. After updating, open the Processes page once and check any row marked **Needs update**.
