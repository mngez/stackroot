## Stackroot 0.3.9

Download and run `Stackroot-Setup-0.3.9.exe` on **Windows 10/11 (64-bit)**. Update over **0.3.8** — sites, databases, and settings are kept.

### Background processes

- **Same PHP line keeps working** — a worker or scheduled task pinned to a PHP patch that is no longer installed moves to another installed patch from the same line (for example 8.0.2 to 8.0.3) instead of stopping.

### Services and PHP

- **New services show up right away** — after you install PostgreSQL (or any other service), it appears on the Dashboard without restarting Stackroot.
- **Newer PHP builds** — PHP 8.5.12, 8.4.27, 8.3.36, and 8.2.35 are available to install. Older patches stay in the list and are marked deprecated, so existing setups keep working.
- **PHP you already installed stays under your control** — if a build is no longer in the download list, you can still select it, change its settings, and uninstall it.
- **Adminer on the Tools page** — install it to manage PostgreSQL, MySQL, MariaDB, and SQLite in the browser. Sign in with server 127.0.0.1 and the database user.
- **Adminer signs in for you** — it uses the username and password from Settings → Databases and the server installed in Services. You land on the database list instead of a blank login form.
- **Adminer names the missing PHP extension** — if MySQL needs `mysqli` or `pdo_mysql`, or PostgreSQL needs `pgsql` or `pdo_pgsql`, the page names this PHP version and points you to PHP → Extensions.
- **A dev proxy can serve the whole domain** — a proxy whose path is `/`, including one with WebSocket support, replaces the site's default location. The domain can point at a socket server without Nginx rejecting the configuration.
- **Sites without PHP can be saved** — an empty site no longer needs a PHP version before Save is available. Laravel and WordPress still ask for one.

### Upgrading from 0.3.8

Your sites, databases, and settings are preserved. No manual steps required. Workers and scheduled tasks whose PHP patch is missing move to another installed patch from the same line on their own.
